# Coding Standard — kompatibilný odkaz

Tento súbor zostáva zachovaný kvôli starším odkazom, záložkám a dokumentom iterácií.

Kanonickým a udržiavaným dokumentom je:

**→ [CODING_STANDARDS.md](CODING_STANDARDS.md)**

Obsahuje aktuálne pravidlá pre:

- PHP 8.5+, strict types a PHPStan level 8,
- TypeScript, React, API barrel a accessibility,
- flat-file SSOT a atomické zápisy,
- `CodePolicyEngine` a write/import gate,
- pluginy, témy a frontend build hranice,
- testy, dokumentáciu a security checklist.

Nepridávaj nové pravidlá do tohto kompatibilného súboru. Zmenu vykonaj v `CODING_STANDARDS.md` a synchronizuj slovenskú aj anglickú vetvu.
