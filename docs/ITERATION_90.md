# Iteration 90 — Editor Workbench (toolbar builder + publishing wizards)

> **Status:** ⏳ planned  
> **Priority:** 🟡 P1  
> **Wave:** Editor & content authoring (post It.79)  
> **Full spec (EN):** [en/ITERATION_90.md](en/ITERATION_90.md)

## Goal (summary)

Replace rigid **editor profiles** with **Settings-driven toolbars** for **Markdown and Tiptap**, plus insert **wizards** (table, callout, mermaid, chart) so non-technical authors never need external Markdown syntax docs. Optional **plugin editor tools** via manifest within the security baseline.

| 90e | `:::chart` + plugin Editor Tool SDK |
